# Chathé — landing page

Landing page for the Chathé tea campaign (student project, Creative Automation, Artevelde University of Applied Sciences).

Live: https://bentebrienne.github.io/chathe-tea/

- `index.html`: the full page (hero with video, story, three rituals, the four blends, The Four Seasons bundle, newsletter sign-up via MailerLite, privacy)
- `assets/`: video, images and logos

Images and video generated with AI (Figma Weave, Adobe Firefly). Page built with Claude.
